# ryojin-note-writing スキル

亮仁（りょうじん）本人が書いたように感じられる、実体験起点のnote記事を設計・執筆・推敲するためのスキル。

## 2つの元ファイルの「良いとこどり」

このスキルは、次の2つを統合して作成した。

| 元ファイル | 主に活かした部分 |
| --- | --- |
| `ryojinvoiceprompt.md`（文体再現プロンプト） | ペルソナ（等身大の一般人＋相棒ちゃぴたん）、具体的なトーン例、生々しい言葉選び、核心をズバッと言い切る断言、追加の禁止語（「本質」「多くの人は」「ここで〇〇の話」／宣伝的な煽り など） |
| `write-ryoto-note.md`（note執筆スキル） | スキルのfrontmatter、事実主義の最優先原則、0〜5.5章の役割設計、AIの位置づけ、避ける表現、作業モード、最終点検チェックリスト |

骨格は執筆スキル側から、文体の濃さ・ペルソナ・禁止事項は文体プロンプト側から取り、`SKILL.md` の「ペルソナ」「文体」「避ける表現と展開」「最終点検」に両者を溶け込ませている。

## サンプル記事

`samples/` に、このスキルの構成・文体・禁止事項に沿って書いた例を3本置いた。いずれもテーマ・読者・変化を1つに絞り、0章のワンシーンから始めて締めで冒頭に戻す形。

1. `01_ai-marunage.md` — AIに丸投げしてた僕が、やっと「相棒」の意味がわかった話
2. `02_mainichi-koushin-yameta.md` — 毎日更新をやめたら、やっと書きたいことが戻ってきた
3. `03_title-nayami.md` — タイトルに2時間かけてた僕が、先に決めるのをやめた話

いずれもスキルの挙動を示すためのサンプルであり、亮仁本人の実体験を記録したものではない。
